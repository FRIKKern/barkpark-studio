# Barkpark Studio · Sunday 15 November 2026

12 pull requests merged. Seven of them rebuilt parts of Sanity's Studio, the editor this Studio matches, so a Sanity project finds more of what it already uses. One fixed the hardest bug of the week: two people typing in one paragraph.

## Two people, one paragraph

Two editors typing in the same paragraph used to lose words: on the old code, a third of them vanished. Now each typed change goes to Barkpark as a small text patch, and both keep every word ([#1251](https://github.com/FRIKKern/barkpark-studio/pull/1251)). The Barkpark half is [FRIKKern/barkpark#26499](https://github.com/FRIKKern/barkpark/pull/26499), which also fixed æ, ø and emoji. Walk-through: [Two editors, one paragraph](2026-11-15-two-editors-one-paragraph.md).

Comments on a piece of text are now checked against the text they quote whenever the document changes from somewhere else ([#1252](https://github.com/FRIKKern/barkpark-studio/pull/1252)).

## New in the editor

- **Translations** ([#1256](https://github.com/FRIKKern/barkpark-studio/pull/1256)). A document type set up for it shows its language as a badge and gets a **Translations** menu: open each language's version, or create one as a linked copy. **Manage translations** shows the whole group.
- **Tables** ([#1254](https://github.com/FRIKKern/barkpark-studio/pull/1254)). In rich text, **Insert → Table** puts in a 3×3 table with a header row. Tab and the arrows move between cells; drag rows and columns to reorder. Review changes names the changed cell ("Table · Row 2, column 1"). At 390 px the table scrolls sideways inside its block.
- **Code** ([#1257](https://github.com/FRIKKern/barkpark-studio/pull/1257)). A code field with syntax colours, a language picker and a filename. Click a line number to highlight the line.
- **Who refers to this** ([#1255](https://github.com/FRIKKern/barkpark-studio/pull/1255)). A form can list the documents that point to the open one, such as "Posts by this author". **Add item** makes a new post already pointing here.

## Working together

- **Tasks** ([#1258](https://github.com/FRIKKern/barkpark-studio/pull/1258)). Open a task in the Tasks sidebar: an activity log in Sanity's words ("changed status to…"), comments with @mentions, reactions and replies, **Duplicate task**, and drafts.
- **Dashboard** ([#1259](https://github.com/FRIKKern/barkpark-studio/pull/1259)). **Dashboard** in the top bar shows unpublished changes, recent edits, my tasks, scheduled publishes, and who is in the Studio now.

## Presentation

Presentation shows your site with editing outlines on top ([#1253](https://github.com/FRIKKern/barkpark-studio/pull/1253)). Hover an outline to see the document's title and icon. Right-click an item in a list to duplicate, remove or move it. Drag it to reorder: the page, the form and a second browser agree at once, and Cmd+Z in the form undoes it.

## Where it is rough

- None of the seven new features was compared side by side with a running Sanity Studio. Each PR says so: the reference Studio has no Sanity server in these lanes, or does not install that plugin. They were built from Sanity's own source and wording instead.
- Also merged: follow-ups to manual ordering ([#1250](https://github.com/FRIKKern/barkpark-studio/pull/1250)), test times re-recorded so CI's browser-test groups stay under 60 s ([#1261](https://github.com/FRIKKern/barkpark-studio/pull/1261)), and the first news article ([#1262](https://github.com/FRIKKern/barkpark-studio/pull/1262)).
